สรุปผู้บริหาร (Executive Summary)

Dab Pose เป็นเกม reaction-time ผ่าน webcam สร้างด้วย Next.js 15 + React 19 + Auth.js v5 (beta) + Neon Postgres + Upstash Redis + Vercel Fluid Compute มี 11 API routes, 70 source files, 15 direct production dependencies

โดยรวม: ดีกว่าค่าเฉลี่ยของโปรเจกต์ขนาดนี้ — รอบล่าสุด (SECURITY_FIXES.md) แก้ CSRF + rate-limit + fail-closed ไปแล้ว ที่เหลือคลัสเตอร์ใน 3 จุด:

  1. Browser hardening ขาด → ✅ ปิดครบ — CSP + X-Frame-Options + HSTS + Permissions-Policy ลง next.config.ts (F-01, F-02, F-03, F-11)
  2. Supply chain → ✅ ปิด — MediaPipe self-hosted ใต้ /public/mediapipe/<version>/ + CSP ตัด jsdelivr ออก (C-01 / F-04)
  3. Leaderboard integrity → ✅ ปิด — proof-of-play token + elapsed integrity check (A-01)

Final state: 0 Critical · 0 High · 1 Medium (AU-01 email verification, needs an email provider choice) · production on next@16.2.6 behind 🟠 Cloudflare proxy with SSL Full strict + Bot Fight Mode + Turnstile gate.

Top 10 prioritized fixes

  3. Proof-of-play token — ใหม่ /api/play/start + ผูกกับ /api/score · ปิด leaderboard forgery · ~3 ชม

Trust boundaries

  • Browser ↔ Vercel edge — WAF + rate-limit · bypass: IP rotation
  • Vercel edge ↔ Function — auth + Origin + regex · ok
  • Function ↔ Postgres — Drizzle parameterized · SQLi ไม่ feasible
  • Function ↔ Redis — JSON.stringify on write · safe as long as server controls input
  • Function ↔ MediaPipe CDN — ไม่มี SRI · CDN compromise = camera + DOM hijack
  • Browser ↔ Google avatar URL — raw img src · bounded but leaks Referer ที่ 2/3 callsites
